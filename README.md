# 宝可梦卡牌开包模拟器

一个在浏览器里运行的宝可梦集换式卡牌（PTCG）开包模拟器。重点是**真实感**：卡面使用自写的物理渲染着色器，模拟清漆层、油墨层与全息金属箔的反射、折射与衍射；卡包、封条与卡牌由刚体物理引擎驱动，卡牌在空中会受空气动力影响飘动、滑翔、翻滚，落到桌面时会发出碰撞声。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 拖动卡包 | 旋转卡包，有惯性和弹性回正，可以翻过来看背面 |
| 沿顶部撕口从左向右拖动 | 撕开封条，撕口跟随手指推进，伴随撕膜声；撕完的封条会飘落到桌上 |
| 向上拖动 / 点击 | 把卡牌从包里抽出来，空卡包会掉到桌上 |
| 点击卡堆 | 翻开最上面一张卡；大奖卡翻开前背面会发光，并在鼠标悬停时响起蓄力音 |
| 移动鼠标 / 陀螺仪 | 倾斜手中的卡牌，观察光泽、彩虹衍射和闪粉 |
| 拖拽甩出卡牌 | 按松手时的速度把卡甩到桌上（真实空气动力学） |
| 再次点击 / 空格 | 把卡轻抛到桌面上整齐排开 |
| 右键拖动 / `L` | 移动台灯位置，实时改变卡面高光与彩虹 |
| 点击桌上的卡 | 拿起来检视：拖动旋转、滚轮缩放、`Esc` 放下 |
| `A` | 自动翻牌 |

设置面板里可以切换环境光（摄影棚 / 日落 / 正午采石场 / 月夜）、台灯色温和亮度、画质等级，以及“稀有度测试”——下一包必出指定稀有度，方便体验每一档特效。

## 收录扩展包与开包概率

宝可梦卡牌 151、璀璨诡幻（Prismatic Evolutions）、超电突围（Surging Sparks）、火箭队的荣光（Destined Rivals）、超级进化（Mega Evolution）、苍空烈潮（Evolving Skies）。

开包结构按各世代公开的统计数据建模（`src/packGen.js`）：朱紫世代为 4 普通 + 3 非普通 + 反闪/ACE SPEC + 反闪或插画稀有槽 + 稀有槽，151 和璀璨诡幻还有精灵球 / 大师球反闪；剑盾世代为 5 普通 + 3 非普通 + 反闪 + 稀有槽。

## 稀有度与特效

| 档位 | 稀有度 | 卡面工艺 | 翻开特效 |
| --- | --- | --- | --- |
| 0 | C / U | 光面清漆 | 翻牌声 |
| 1 | 反闪 | 除插画外全卡闪粉箔 / 精灵球箔 | 扫光、星点 |
| 2 | R 稀有 | 插画框碎冰马赛克全息 | 白光闪烁、星芒粒子 |
| 3 | RR / V / ACE SPEC | 全卡全息 + 轻压纹 | 属性色冲击波、补光、震屏 |
| 4 | SR / AR | 指纹压纹全息 / 柔光闪粉 | 光束、推镜、和弦；AR 为花瓣光斑与竖琴琶音 |

所有特效都会发出真实光源（场景中的点光源），照亮卡牌与桌面，而不只是叠在画面上的贴图。

## 渲染：卡面的物理模型

着色器位于 `src/card/cardShader.js`，卡面从上到下分为三层：

1. **清漆层**：折射率 1.5 的电介质，GGX 微表面高光 + Schlick 菲涅尔。灯被当作有尺寸的球形光源处理（Karis 2013 的波瓣展宽），所以高光是一块柔和的灯影，而不是一个针尖。全图卡的压纹在这一层，压纹法线由程序指纹纹理与插画亮度梯度共同生成，高光会沿着纹路流动。
2. **油墨层**：印刷色等效为滤色片。光线经清漆**折射**（斯涅尔定律）进入，被油墨过滤后到达底层，再折射出去，进出两次都按菲涅尔透射率衰减。
3. **底层**：
   - 纸张：Oren–Nayar 粗糙漫反射，模拟纸纤维的**散射**（比朗伯更“哑”、背光侧更亮）。
   - 全息金属箔：零级为金属 GGX 反射；衍射级按反射光栅方程 `d·(sinθᵢ + sinθₒ) = mλ` 计算，对点光源求出每一级的波长，通过 CIE 1931 色匹配函数（Wyman 2013 拟合）转换成颜色；对环境光照则逆向求解“哪个方向的光会被光栅衍射进眼睛”，对多个波长采样环境贴图并积分光谱，因此 HDR 环境中的窗户和灯也会在卡面上拉出彩虹。
   - 不同工艺使用不同的光栅场：直线全息、碎冰马赛克（Voronoi 单元各自的光栅方向、周期与倾角）、宇宙圆点、闪粉反闪、精灵球/大师球图案、指纹压纹、金箔拉丝。
   - 金属闪粉：每个微小单元是一片随机倾斜的小镜子，只有在光源、视线满足镜面条件时才会闪一下，并带有衍射色。

卡牌是有厚度的圆角模切几何体，侧边能看到白色纸芯和中间的黑色遮光层；手持甩动时卡牌会有轻微的弯曲形变。

场景：Three.js WebGL2，物理正确的光照单位，Khronos PBR Neutral 色调映射，PMREM 预过滤的 HDR 环境光照，PCF 软阴影，4× MSAA，HDR 泛光，镜头暗角与色差，胶片颗粒。卡包是金属化薄膜材质（金属度/粗糙度贴图、褶皱与压痕法线、薄膜干涉清漆），内侧为银色铝箔。

## 物理

`src/physics.js` 使用 [Rapier](https://rapier.rs) 刚体引擎（厘米-克-秒单位制），并为卡牌加入薄板空气动力学模型：

- 法向压差阻力系数随攻角变化（小攻角约 `2πα`，正面迎风饱和到约 1.2），所以平着下落的卡终端速度约 2 m/s；
- 压力中心在小攻角时前移到四分之一弦长处，产生俯仰力矩，卡牌因此会摆动、滑翔、翻滚；
- 平行于板面的摩擦阻力、二次的旋转空气阻尼；
- 接触力事件驱动落桌的“啪”声，音量随冲击力变化。

手中的卡包和卡牌由 6 自由度阻尼弹簧驱动，带惯性、过冲和回弹；松手时把指针速度换算到世界坐标，交给刚体继续运动。`npm run check:physics` 会在 Node 里跑几个下落/抛掷的数值检查。

## 卡面素材

- 卡牌数据来自 [PokemonTCG/pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data)，已精简后放在 `public/data/`。
- 运行时优先加载 `images.pokemontcg.io` 的官方卡图；如果网络或跨域策略不允许，会自动改用程序绘制的完整卡面（属性边框、名称、HP、招式与能量、弱点/撤退、插画师、编号与稀有度标志），立绘来自 [PokeAPI sprites](https://github.com/PokeAPI/sprites)。
- HDR 环境贴图与木纹贴图来自 [Poly Haven](https://polyhaven.com)（CC0），取自 three.js 示例资源。
- 所有音效由 WebAudio 实时合成。

## 运行

```bash
npm install
```

```bash
npm run dev
```

然后打开终端里显示的地址（默认 http://localhost:5173）。需要支持 WebGL2 的浏览器；独立显卡上建议选择“极致”画质。

构建静态站点：

```bash
npm run build
```

产物在 `dist/`，可以直接部署到任何静态托管。仓库自带 GitHub Pages 工作流（`.github/workflows/pages.yml`），推送到 `main` 后在仓库设置里把 Pages 来源设为 GitHub Actions 即可。
